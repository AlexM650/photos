# Project setup

This is a React and TypeScript photo-grid app built with Vite and Tailwind CSS.

## Run on Replit

Use the **Start application** workflow. It runs:

```sh
npm run dev
```

The Vite development server listens on `0.0.0.0:5000` and permits Replit's proxied preview hosts.

## Checks

- Type check: `npm run lint`
- Production build: `npm run build`
